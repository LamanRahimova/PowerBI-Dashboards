# HR Dashboard (Power BI)
 
## Overview
 
This Power BI dashboard provides HR analytics and workforce insights to support data-driven decision-making. The report is designed to help HR professionals and management monitor key workforce metrics, identify trends, and analyze employee-related data.
 
## Dashboard Pages
 
### 1. Home
Executive summary page displaying key HR KPIs and workforce indicators.
 
Typical metrics may include:
- Total Employees
- Male Employees
- Female Employees
- Average Age
- Attrition Rate
- Other HR performance indicators
 
### 2. Action
Analytical page focused on HR trends and actionable insights.
 
Features:
- Workforce distribution analysis
- Employee demographics
- Department-level analysis
- Trend visualizations
- Comparative charts
 
### 3. Detail
Detailed employee-level information.
 
Features:
- Employee records
- Drill-down analysis
- Filtering and segmentation
- Detailed HR reporting tables
 
## Key Features
 
- Interactive Power BI visualizations
- KPI monitoring
- Employee demographic analysis
- Workforce trend analysis
- Detailed employee reporting
- Drill-through and filtering capabilities
 
## Technologies Used
 
- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query
- Data Modeling
 
## File Structure
 
HR Dashboard.pbix
 
## Usage
 
1. Open the `.pbix` file using Microsoft Power BI Desktop.
2. Refresh the data source if required.
3. Navigate through dashboard pages using the built-in navigation buttons.
4. Apply filters and slicers to explore workforce insights.
 
## Business Value
 
This dashboard enables organizations to:
 
- Monitor workforce composition
- Support HR planning
- Identify workforce trends
- Improve reporting efficiency
- Enhance decision-making through data visualization
